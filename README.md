# 🌳 עץ חיים משפחתי — FamilyBless (FB)

**גרסה:** 0.0.1  
**תאריך:** 05.11.2026  
**יוצר:** לאון יעקובוב (AnLoMinus) · Cyber Shamanic

גלריה עצמאית של **21 קלפי ברכה מאוירים** למשפחה עם נוסחים שונים. הקלפים 12–21 כוללים נוסחים מקוריים בני 12 שורות, מחולקים לבתים.

## 🚀 הפעלה

1. חלצו את ה־ZIP כך שהתיקייה `השורות` תישאר שלמה.
2. פתחו את `index.html` בדפדפן מודרני. אין צורך בהתקנה, באינטרנט או בשרת.
3. בחרו קלף, הורידו PNG, חפשו לפי נושא, סננו סדרות או סמנו מועדפים.

המועדפים נשמרים באחסון המקומי של הדפדפן במכשיר שבו משתמשים. הם אינם מסתנכרנים בין מכשירים.

## 📁 מבנה

```text
השורות/
├── index.html          אתר הגלריה
├── style.css           עיצוב רספונסיבי
├── app.js              חיפוש, סינון, תצוגה, הורדה ומועדפים
├── data.js             רשימת הקלפים
├── assets/cards/       21 קובצי PNG
├── manifest.json       מידע קריא למכונה
├── BLESSINGS.md        נוסחי ברכות לקריאה ועריכה
├── CHANGELOG.md        יומן גרסאות
├── TODO.md             תוכנית פיתוח
└── CREDITS.md          זכויות וקרדיטים
```

## 🔎 מגבלות ותכנון

התמונות הופקו כמקשה אחת הכוללת איור וטקסט. יש לבדוק את רינדור האותיות בעברית לפני הפקה לדפוס. נוסחי הטקסט המתועדים ב־`BLESSINGS.md` הם בסיס לשכבת טקסט מדויקת במהדורה עתידית.

אין באתר חשבון משתמש, שרת, איסוף נתונים או צורך בהרשאות.
